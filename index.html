📖 راهنمای اتصال از بازی (SA-MP / open.mp)

چون GitHub Pages استاتیک است، بازی باید مستقیم به Supabase REST API ارسال کند.

آدرس POST:
https://YOUR_PROJECT.supabase.co/rest/v1/chat_logs

هدرهای لازم:
apikey: YOUR_ANON_KEY
Authorization: Bearer YOUR_ANON_KEY
Content-Type: application/json
Prefer: return=minimal

بدنه (JSON):
{"global_string_a": "متن پیام شما از بازی"}

مثال با پلاگین HTTP / webrequest (بسته به پلاگین شما فرمت کمی فرق می‌کند):
مقدار global_string_a را دقیقاً همان‌طور که بازی می‌فرستد نگه دارید.

چت‌های تکراری (متن دقیقاً یکسان) به خاطر UNIQUE در دیتابیس اضافه نمی‌شوند.
